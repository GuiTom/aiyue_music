# 爱悦 · 本地音乐播放器

Flutter 原生应用，参照提供的设计稿实现深色背景、荧光绿播放按钮、大封面和文件夹播放列表。手机为单列，桌面宽屏为双列。封面图片从用户提供的设计稿裁切，仅作为默认展示图。

## 运行

```sh
flutter pub get
flutter run -d macos
# 或在连接 Android 设备后：
flutter run -d android
```

macOS 需要完整 Xcode（仅 Command Line Tools 不够）和 CocoaPods。Windows/Linux 请在对应系统运行 Flutter，并安装该平台的 Flutter 桌面构建依赖。不提供 Web 版：本项目直接访问本地文件系统。

## 使用

### 内部曲库与播放列表

从本地文件夹勾选或从 B站导入的歌曲，会保存到 App 私有的 `music_library` 目录，同时加入“内部曲库”和“播放列表”。以后播放不再依赖原文件夹持续授权。播放列表中的菜单支持置顶和移除；“从播放列表移除”只修改列表，不删除内部 MP3。内部曲库中的菜单支持添加到播放列表和永久删除；永久删除会在确认后同时删除播放列表记录与 App 私有存储中的 MP3 文件。

播放控制区使用同一个模式按钮，依次切换“全部循环、单曲循环、乱序播放”，每次切换都会显示提示。

### B站分享链接导入

曲库右上角“…” → “从 B站导入 MP3”（空曲库也有入口），粘贴完整分享文字、b23.tv 短链接或 bilibili.com/video 链接，先解析并确认标题，再下载并导入。支持链接中的 `p` 分P参数；没有指定则导入第1P，不会批量下载整个合集。音轨通过 FFmpeg 的 libmp3lame 实际转码为 MP3，并非修改后缀。

下载歌曲保存在应用私有目录，可离线播放、重启恢复，重新导入本地文件夹时保留；卸载应用会删除这些文件。下载与转换显示进度，失败清理临时文件。仅支持可公开访问的普通视频，不提供登录或绕过付费、地区及访问限制的能力；请仅下载有权保存的内容。B站接口变化或限流可能导致导入失败。

新增原生 FFmpeg 插件后须停止应用并重新运行，不能仅热重载。Android 已验证构建；其他平台的原生转换尚未验证。FFmpeg 依赖为 full-gpl 发行版，发布应用时需遵守其 GPL 及相关第三方许可。

### 锁屏与后台播放

Android 接入媒体播放前台服务和系统媒体会话：播放歌曲后，可在通知栏、锁屏界面或耳机按键控制播放/暂停、上一首、下一首和进度。锁屏、切换应用后继续播放；来电和其他应用的音频焦点由音频会话处理。系统强制停止应用后不会继续播放。iOS 已配置音频后台模式，但需在 iOS 实机验证系统锁屏行为。

### 均衡器

XBS 预设使用指定参数：60Hz +4dB、200Hz +2dB、910Hz 0dB、3.6kHz +2dB、14kHz +1dB。设备频段不一致时按对数频率插值，并限制在设备支持的增益范围内。点击预设会自动启用均衡器并保存设置。

Android 播放歌曲后点击“均衡器”，打开音效开关，调节设备支持的各频段增益；提供平直、低音、人声、流行预设，设置自动保存在本机并在下次播放恢复。其他平台暂不支持均衡器。

扫描文件夹后会显示 MP3 勾选窗口，默认不选中歌曲。支持搜索、全选当前搜索结果和清空选择，确认后才更新播放列表；取消不改变现有列表。重启后只恢复上次勾选的歌曲。

点击“文件夹”或“导入音乐文件夹”，选择包含 MP3 的目录，递归扫描子目录；点击歌曲播放。支持拖动进度、上一首/下一首、随机、顺序/列表循环/单曲循环、0.75–2 倍速、15–60 分钟定时停止、文件名搜索和收藏。文件夹路径与收藏记录保存在本机，不上传音频。

macOS 已配置用户选择文件的只读权限。沙盒权限在重启后可能需要重新选择文件夹授权。Android 通过系统 Storage Access Framework 选择目录，保留读取授权，递归查询文档 URI 并直接播放 content URI，无需全盘访问权限；系统禁止选择的受保护目录无法导入。iOS 文件夹访问需要在实机验证，不承诺可遍历任意外部提供商目录。

## 验证

### Android 包体积

Android 仅使用 FFmpeg 音频发行版（保留 `libmp3lame`），不再打包 full-gpl 视频滤镜能力；Android 未使用的 MPV 库也已移除。日常 `flutter run` 生成的是包含调试内核和多个 CPU 架构的 Debug 包，体积不能代表发布包。发布时使用：

```sh
flutter build apk --release --split-per-abi
```

现代 Android 手机通常安装 `app-arm64-v8a-release.apk`。不要把未分架构的 `app-debug.apk` 作为正式安装包分发。

Android 构建已在项目 Gradle Wrapper 中关闭 configuration cache，以兼容 Flutter 3.35 的 `DebugMinSdkCheck`；即使全局 `~/.gradle/gradle.properties` 开启此缓存也不会影响本项目。普通构建缓存保持原设置。依赖的“newer versions incompatible”提示不是编译错误，无需为此强制升级依赖。

```sh
flutter analyze
flutter test
```

目前没有 ID3 标签/嵌入封面解析和歌词。时长从实际音频读取，不显示虚构码率与歌曲数据。
